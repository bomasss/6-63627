# Ар-музей «Оружие Победы» — локальная QR + AR выставка

Восемь самостоятельных страниц (по QR-коду на каждую). Страницы **не связаны**
между собой: сканер телефона открывает сразу страницу экспоната с 3D/AR-моделью,
которую можно вращать пальцем, а внизу — интересные факты. Сайт хостится
на ноутбуке в локальной Wi-Fi сети.

## Быстрый старт (на ноутбуке)
```bash
pip install -r requirements.txt      # один раз: библиотека для QR
python serve.py                      # запустит сервер на порту 8000
```
Сервер сам определит IP ноутбука и **сгенерирует свежие QR-коды** под него.
Затем:
1. Откройте на ноутбуке `http://localhost:8000/qr-print.html` и распечатайте листы
   (или возьмите готовые PNG в `ar-site/qrcodes/`).
2. Разложите распечатки у стендов.
3. Телефоны в той же Wi-Fi сети сканируют камерой → открывается страница экспоната.

## Кладём модели (обязательный шаг!)
Скачанные модели конвертируйте в `.glb` (например, через [Blender](https://www.blender.org):
File → Import, затем File → Export → glTF 2.0 `.glb`) и положите в `ar-site/models/`
с именами из таблицы ниже (имена задаются полем `model_file` в `ar-site/js/data.js`):

| Файл в `ar-site/models/` | Экспонат |
|---|---|
| `suvorov-uniform.glb` | WW2 Soviet Uniform |
| `russian-pilot.glb` | Russian Pilot |
| `il2-sturmovik.glb` | Ilyushin Il-2 Sturmovik |
| `yak-9.glb` | Yak-9 |
| `t-34.glb` | Tank T-34 |
| `bmp-1.glb` | BMP-1 |
| `t-34-85.glb` | T-34-85 |
| `t-70.glb` | T-70 |

Пока файл не положен — страница показывает вращаемую 3D-заглушку и подсказку.
Быстрый способ проверить модель без папок: кнопка **«📁 Модель»** на странице
(или перетащить .glb прямо на окно просмотра).

## Что где лежит
```
serve.py            — локальный сервер (хостит ar-site/, печатает IP, обновляет QR)
make_qrcodes.py     — генерация QR-кодов (python make_qrcodes.py [--ip .. --port ..])
build_pages.py      — пересборка 8 страниц после правок js/viewer.js или data.js
setup_offline.py    — (опционально) скачает three.js и шрифты для работы БЕЗ интернета
ar-site/
  index.html        — служебная страница организатора (список экспонатов)
  qr-print.html     — листы QR для печати (Ctrl+P)
  css/style.css     — светлый строгий «военный» стиль, mobile-first
  js/data.js        — ЕДИНАЯ база: названия, категории, факты, имена моделей
  js/viewer.js      — исходник вьюпорта (встраивается в страницы сборкой)
  js/vendor/        — сюда setup_offline.py кладёт three.js для офлайна
  pages/<id>.html   — 8 самостояльных страниц экспонатов
  models/           — файлы .glb/.gltf (+ .usdz для iPhone)
  qrcodes/          — сгенерированные PNG по одному на страницу + _all_urls.txt
```

## Возможности страницы экспоната
- **Вращение**: один палец/мышь — орбита; щипок/колесо — зум; кнопка «↻ Вращение» — автовращение.
- **Факты** под моделью — берутся из `js/data.js` (правьте там, затем `python build_pages.py`).
- **AR**: кнопка «AR» на Android (Chrome ≥ 81, WebXR) ставит модель в комнату через камеру.
  На iPhone/iPad кнопка использует Apple Quick Look — для этого положите рядом
  `.usdz`-версию модели (конвертируется из GLB онлайн-сервисами или Blender-плагином).
- Если интернета нет, выполните `python setup_offline.py` один раз — three.js и шрифты
  будут браться локально (страницы пересоберите: `python build_pages.py`).

## Частые проблемы
- **Телефон не открывает по QR** — телефон и ноутбук в одной Wi-Fi сети; проверьте IP
  в консоли `serve.py`; брандмауэр Windows может блокировать Python — разрешите его
  для частной сети. Идеально — раздайте Wi-Fi с самого ноутбука (точка доступа).
- **IP сменился** — перезапустите `python serve.py`: QR перегенерируются автоматически,
  перепечатайте листы из `qr-print.html`.
- **Модель не видна целиком** — нажмите «⊙ Сброс».
