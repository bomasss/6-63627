Оружие Победы

Локальная AR-выставка. Для посетителей страницы доступны только по QR-кодам — экспонаты не связаны между собой.

Нажмите «Печать» (Ctrl+P / ⌘P). Каждый QR — отдельный стенд. Перед печатью убедитесь, что IP ниже совпадает с адресом ноутбука.
Это служебный экран организатора.
Печать всех QR-кодов одним листом: откройте qr-print.html (эта страница).
Если IP ноутбука изменился — перегенерируйте коды: python make_qrcodes.py (или python make_qrcodes.py --ip 192.168.1.50 --port 8000).
